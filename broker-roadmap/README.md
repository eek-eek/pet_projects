# Дорожная карта проектов брокерского бизнеса

Цель — собрать дорожную карту доработок и продуктовых инициатив брокера, где каждый проект связан с измеримым эффектом на маржинальный доход.

## Этапы

| Этап | Результат | Статус |
|---|---|---|
| 1. Метрики | Дерево метрик от маржинального дохода до драйверов, паспорта метрик, модель чувствительности | В работе: выбор метрик из стандартного набора отрасли — [01b_best_practice_metrics.md](01b_best_practice_metrics.md) |
| 2. Гипотезы | Шаблон карты гипотез (ИТ и не ИТ, выделение сервисов в продукты), привязка к драйверам | Следующий |
| 3. Трудозатраты | Оценка гипотез по ролям и ресурсам | — |
| 4. Дорожная карта | Приоритизация и раскладка по времени с учётом ёмкости команд | — |

## Как работать с моделью

1. Откройте `broker_roadmap_model.xlsx`, лист «Вводные». Замените иллюстративные значения (синий шрифт на жёлтом фоне) фактическими данными по сегментам.
2. Сверьте «Сводку» с управленческой отчётностью: чистая выручка и маржинальный доход по сегментам должны сойтись в пределах ±5%.
3. Лист «Чувствительность» показывает, сколько маржинального дохода даёт улучшение каждого драйвера. Эти значения используются для оценки гипотез на этапе 2.

Файл модели — источник правды для данных. Генератор `tools/build_model.py` нужен только для перестройки структуры. Существующий файл он не перезапишет без флага `--force`. После сборки формулы пересчитываются при открытии файла в Excel.

## Принятые решения

| Дата | Решение |
|---|---|
| 07.10.2026 | Модель универсальная, без привязки к юрисдикции; ориентиры — публичные брокеры |
| 07.10.2026 | Сегменты: масс-розница, состоятельные, институционалы и корпоративные. B2B и партнёрские продукты — вне периметра |
| 07.10.2026 | Верх дерева — маржинальный доход, а не выручка. Регуляторные задачи — отдельный обязательный трек без денежной оценки |
| 07.10.2026 | Формат: Excel-модель и описание в markdown в этом репозитории |
| 07.10.2026 | Горизонт оценки: оба горизонта, гипотезы ранжируются по долгосрочному эффекту, бюджет проверяется по году 1 |
| 07.10.2026 | Клиент: фондированный — активы от ≈$100 в эквиваленте; активный — любая операция за месяц |
| 07.10.2026 | «Выделение сервисов в продукты» — внутренние сервисы со своим P&L; учитывается только эффект брокера |
| 07.10.2026 | Ставки: план на сценарии снижения (`RATE_SHIFT` = −1 п.п., величина — допущение) |
| 07.10.2026 | Данные: работаем на ориентирах публичных брокеров, факт подставим позже |
| 07.10.2026 | Переход МР → СК отдельным драйвером не моделируется, считается внутри гипотез |
| 07.10.2026 | Срок дорожной карты: 3 года по полугодиям |
