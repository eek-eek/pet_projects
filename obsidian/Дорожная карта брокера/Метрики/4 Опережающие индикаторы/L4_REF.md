# L4_REF — Доля привлечения по рекомендациям

**Что это.** Доля новых фондированных клиентов, пришедших по реферальной программе.

**Как считать.** Новые фондированные по рефералам ÷ все новые фондированные

**Двигает драйверы:** [[CAC]] (Затраты на привлечение одного фондированного клиента (маркетинг, агентские, бонусы)), [[LEADS]] (Заявки на открытие счёта за период (ИК — потенциальные клиенты в воронке продаж))
